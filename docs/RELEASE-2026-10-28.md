The desktop repository was renamed from `multisiteprobe-desktop-community` to `probelune-desktop`. Its existing history, `master` branch and local-data migration identities were retained. Existing local documentation/dependency work was preserved in the new commit.

Each repository includes an English-default README, a separate Chinese README, GPL-3.0-or-later license, changelog, contribution guide, code of conduct, security policy, issue/PR templates and CI. Runtime data, local credentials, build artifacts and signing material are ignored. The root repository contains product documentation and helper scripts only; it does not combine or vendor the source projects.

The published contract dependency is `v0.1.1`; its immutable tag points to the protocol implementation commit, followed by documentation-only changes on `main`. Application versions are independent: dashboard/node/mobile `0.1.0`, desktop `1.6.0`.

See [acceptance](acceptance.md) for actual runtime evidence and external release checks. Passing CI does not claim signed installers, App Store/Google Play submission, physical-device push delivery or production-scale geographic availability. Follow the relevant project's README to deploy or build it.
